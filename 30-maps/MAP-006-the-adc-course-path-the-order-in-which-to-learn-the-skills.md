# The ADC course path: the order in which to learn the skills

A proposed path in four modules. The professional skills (pitch, portfolio, client) run in parallel, from the first module.

| Module | Skills | Outcome of the module |
|---|---|---|
| 1. Foundations | MKT, INS, HIS | the student understands the market, the consumer and where the profession comes from |
| 2. Strategy | BRD, ADV, BRF | the student writes a brand strategy and a creative brief |
| 3. Creative | IDE, CPY, ART, STO | the student produces an integrated campaign starting from the brief |
| 4. Channels and the future | DIG, SOC, EXP, AIM | the student plans distribution, measurement and the use of AI |
| In parallel | PIT, PRT, CLI | presentation, portfolio and the client relationship, practiced on every project |

The complete workflow of a project, which crosses all the modules: [[MAP-001-the-agency-workflow-from-the-business-problem-to-the-pitch|MAP-001]].
