# Agency brief models share the same core, but each one optimizes something else: inspiration, conciseness, context, process or evidence

> **The idea in one sentence:** under different forms, every brief asks who, what change, what single message and what evidence; they differ in what they add around that.

## Explanation

Compared with the six McTigue and Rucker components ([[BRF-005-the-mctigue-and-rucker-brief-has-six-components-and-fits-on|BRF-005]]), the set looks like this (✓ = explicit section, ~ = implicit or partial, ✗ = missing):

| Component | Euro RSCG | Get/To/By | Naked | Red Cell | Singleton O&M |
|---|---|---|---|---|---|
| Objective / role | ✓ (business) | ~ (TO) | ✓ (business problem) | ✓ | ✓ (role) |
| Desired response | ~ | ✓ | ✓ (desired effect) | ✓ | ✓ (think/feel/do) |
| Target | ✓ | ✓ | ✓ ("richer" picture) | ✓ | ~ (the audience, in the insight) |
| Insight | ✓✓✓ (consumer, brand, category) | ✗ | ~ ("or ask us") | ✗ | ✓ (helpful) |
| Single message | ✓ (single-minded thought) | ✓ (BY) | ✓ | ✓ (proposition) | ✓ (single most important point) |
| Evidence / RTB | ~ (why they will care) | ✓ (BECAUSE) | ✗ | ✓ (support + end benefit) | ✓ (emotional, sensual, rational) |
| Personality / tone | ✓ | ✗ | ✗ | ✓ (tonality) | ✓ (selective) |
| Mandatories | ✓ | ✗ | ✗ | ✓ | ✓ |
| Measurement | ✓ | ✗ | ✓✓ (hard, soft, buzz) | ✗ | ✗ |
| Process / approvals | ✓ (4 steps) | ✗ | ~ | ✓✓ (timetable, 5 signatures) | ✓ (client signature) |
| Context / history | ✗ | ✗ | ✓✓ | ✗ | ✗ |

**What each one optimizes:**

- *Euro RSCG* ([[BRF-017-the-euro-rscg-australia-brief-model-the-task-three|BRF-017]]): the depth of the insight (triangulation) and the internal filter before the client.
- *Get/To/By* ([[BRF-016-the-get-to-by-brief-puts-the-whole-strategy-into-one|BRF-016]]): conciseness and behavior change; it is a clarity test.
- *Naked* ([[BRF-018-naked-brief-an-informative-and-inspirational-brief-built-on|BRF-018]]): context and learning; the richest evaluation.
- *Red Cell* ([[BRF-019-the-red-cell-brief-eight-requirements-execution-hints-and-a|BRF-019]]): process and accountability; the proposition → support → end benefit ladder.
- *Singleton O&M* ([[BRF-020-the-singleton-ogilvy-mather-brief-the-role-of-the|BRF-020]]): credibility: the single point is tied to evidence, including sensual evidence.

**What all of them lack:** an explicit competitive frame of reference, which McTigue and Rucker consider essential yet often overlooked. Only Euro RSCG and Naked have measurement, the component the authors ask for in every brief.

**Two forms from other sources** confirm the core. Percy and Rosenbaum-Elliott's one-page brief ([[BRF-006-the-creative-brief-fits-on-one-page-in-three-blocks-task|BRF-006]]) adds the source of business and the brand attitude strategy from the Rossiter-Percy grid. The Publicis form in *La boîte à outils* ([[BRF-003-the-client-brief-asks-the-question-and-the-creative-brief|BRF-003]]) adds the brand's values and identity, plus the deliverables.

## Application

- Choose the form by the problem: a quick social media brief → Get/To/By; a brand relaunch with a long history → Naked; a large production with many approvers → Red Cell; a parity category where the evidence decides → Singleton O&M.
- Whatever the form, add the frame of reference and the measurement indicator in the margin.
- Exercise: fill in the same case in two forms and discuss what each one brought to light.

## Example

The Stark case ([[BRF-015-the-stark-cloud-solutions-case-how-a-good-brief-becomes-a|BRF-015]]) filled in on Get/To/By fits into one sentence but loses the insight and the measurement; filled in on Euro RSCG, it brings to light the triangulation that leads to the single-minded thought "more secure than your own server". The same case, two forms, two different lessons.

## Questions

- All five forms fit on one or two pages. Does that confirm McTigue and Rucker's "less is more" principle?
- What section would you add for ideas that are not ads (activations, products, partnerships)?
