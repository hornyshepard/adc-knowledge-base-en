# A search ad is written as a set of interchangeable pieces, and each one has to work on its own

> **The idea in one sentence:** in responsive ads, the copywriter no longer writes a single final text but a set of components from which the machine assembles and tests combinations.

## Explanation

**The anatomy of the ad** (Sachdev): the "Ad" label, the display URL, the headline (the largest type), the description (the value and the "alluring mechanisms": discounts, free shipping) and the ad extensions: call, sitelink (links to specific pages), callout (unique selling points, for example free delivery), price, location. Relevant extensions raise the click-through rate and may strengthen ad rank.

**Responsive search ads** (RSAs): the advertiser supplies up to 15 headlines and 4 descriptions; Google combines them dynamically and looks for the combination with the best click-through rate and the highest conversion rate. Bing chooses the headline and description that are most relevant for each query and search user. SRC-032 adds the benefits: higher CTR, time saved, reach across more search terms.

**The content rules** in Sachdev:

- relevance to the search: the keyword appears in the ad, but not in every headline;
- fit with the brand: an official Lamborghini dealer does not write "cheapest place to buy a Lambo";
- personalized to the search, not general copy;
- benefits, not only features (what the stainless-steel straw does for you, not only the material);
- a clear CTA: "free delivery", "pick up today", "compare products side-by-side";
- cultural sensitivity: the number 4 is considered unlucky in China, and "frog" may be offensive to the French;
- continuous A/B testing.

## Application

- Write the headlines by category: benefit, offer, proof, CTA, brand, keyword variants.
- Check each headline against each description: every combination has to make sense and respect the brand's tone.
- Add negative keywords and sitelinks to the most relevant pages.

## Example

The book's ad for reusable straws combines a description with a discount and free shipping, a sitelink to the collection and phrases that intrigue, such as "expert reviews" or "variety of sizes & colors".
