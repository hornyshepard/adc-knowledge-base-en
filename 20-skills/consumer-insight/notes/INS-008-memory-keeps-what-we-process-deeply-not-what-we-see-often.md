# Memory keeps what we process deeply, not what we see often

> **The idea in one sentence:** how long a memory lasts depends on how deeply (semantically) the information was processed, not on the number of exposures; that is why we cannot draw a banknote we use every day.

## Explanation

Fennis and Stroebe summarize three models of memory that are useful to advertisers:

| Model | Central idea | Relevance |
|---|---|---|
| Atkinson-Shiffrin (1968) | sensory memory (less than a second) → working memory (5–7 items, Miller) → long-term memory | working capacity is tiny; what is not rehearsed is lost |
| Levels of processing (Craik & Lockhart, 1972) | not the system but the depth of processing decides how long a trace lasts: orthographic < phonological < semantic | an ad that forces people to process meaning is remembered better |
| Working memory (Baddeley & Hitch, 1974; 2000) | a central executive coordinates the phonological loop (sound, about 2 seconds), the visuospatial sketchpad and an episodic buffer | sound and picture can be processed at the same time, without interference; the consideration set "lives" in the episodic buffer |

The proof that exposure is not enough: people cannot reproduce a coin they are likely to have seen thousands of times (Nickerson & Adams, 1979). Attention and semantic processing are what fix the information.

Long-term memory has an explicit component (episodic, "I saw the ad last night", and semantic, "what I know about the brand") and an implicit, unconscious one that matters a great deal for advertising.

The serial position effects (primacy, recency) found in lists also appear in commercial breaks.

## Application

- Build ads that ask for a small operation on meaning (a question, a metaphor to decode), not only a repetition of the name.
- Combine the auditory channel with the visual one: they load different subsystems.
- Do not overload: a spot with seven benefits exceeds working memory.

## Example

The 5 lei banknote: you see it every day, but you cannot draw it. This is the book's example (the £5 or €5 note) applied locally.

## Questions

- If semantic processing fixes the memory, why does simple repetition still work in low-involvement categories?
- What role does implicit memory play when processing is shallow?
