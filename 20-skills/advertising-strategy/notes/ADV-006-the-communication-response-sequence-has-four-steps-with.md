# The communication response sequence has four steps with compounding probabilities, so a message fails if a single step fails

> **The idea in one sentence:** even with 50% success at each step, McGuire's paradigm yields fewer than 2% buyers; hence the modesty we need when we promise effects from advertising.

## Explanation

The authors start from William McGuire's **information processing paradigm**, a theory of attitude change. For a persuasive message to work, a person must complete six steps: the message is **presented**, the person **attends** to it, **comprehends** it, **yields** to its arguments, **retains** the conclusion and then **behaves** accordingly.

Because this is a hierarchy, the probabilities multiply: 0.5⁶ ≈ 0.016. The authors conclude that you cannot expect great changes in behavior as a direct result of advertising, even when everything works.

For advertising and promotion, they compress the six steps into the **communication response sequence**:

| Communication response sequence | McGuire |
|---|---|
| 1. Exposure | presentation |
| 2. Processing: attention, learning, sometimes acceptance, plus emotional responses | attention, comprehension |
| 3. Communication effects, durably linked to the brand | yielding, retention |
| 4. Target audience action | behavior |

The sequence usually has to be **repeated**. Only direct response advertising goes through it once and ends with a purchase. After trial, experience with the product changes how the next messages are processed. Competitive interference then weakens the effects, so the cycle starts again.

## Application

- When you diagnose a campaign that "isn't working", ask in turn: was it seen? was it processed correctly? did it produce the intended effect? did action follow?
- Each step has a different lever: media (exposure), creative (processing), positioning (effects), promotion and distribution (action).
- Use the arithmetic of probabilities to temper the promises made to the client.

## Example

Burger King's Whopper Detour campaign asked for many successive actions: download the app, go to a McDonald's, order, pick up at Burger King. Each step lowers the overall probability, so the reward (a one-cent Whopper) had to be very strong.

## Questions

- Which step of the sequence is most fragile on TikTok? And on a street billboard?
- The model assumes a fixed order. Which authors in the library would contest the order of the effects?
