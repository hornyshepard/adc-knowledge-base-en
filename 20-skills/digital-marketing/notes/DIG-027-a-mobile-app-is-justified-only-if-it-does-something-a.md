# A mobile app is justified only if it does something a responsive website cannot do

> **The idea in one sentence:** a mobile-friendly website is no longer optional; an app is an expensive strategic decision, justified only by functions the website does not offer.

## Explanation

There are three options for the mobile website: a **stand-alone site** (m.yourbrand.com: outdated, it needs redirects and double maintenance), **responsive design** (a single fluid template that adjusts to the screen width; cheaper, preferred by Google) and **adaptive design** (*dynamic serving*: separate layouts for about six common screen widths; more expensive, but it can give a better experience on each device).

The question for an app is a different one: "What can an app offer that a mobile site can't?" The authors list the cases where it is justified: the brand has a clear strategy for the app (retention, payment, ordering); the task is clearly easier in an app (calling a cab from the sidewalk); the target audience is heavily mobile; it needs interactivity (a game), personalization (financial services), phone functions (click to call) or offline access.

The economic argument in chapter 5 is harsh: only about 25% of apps are used once after download, and 80% are deleted within the first 90 days. The difficulty of getting the installation pales next to the difficulty of getting repeat use. The KPIs for any app are the retention rate and CLV. Google found, in tests with 119 mobile users, that people on mobile are highly goal-oriented: they want what they need right away and on their own terms.

## Application

- When the client asks for "a brand app", answer with the authors' question and the abandonment figures. Propose an excellent responsive website first.
- If an app makes sense, write the brief around a repeated task (ordering, paying, loyalty), not around brand content.
- On mobile: font of at least 12 px, CTAs that are easy to tap, short forms, images sized for the device.

## Example

The **Starbucks** app is the positive example: customers visit several times a week, and the app lets them order, pay and use the loyalty program. The same goes for banking apps and for Allianz MyHealth, which photographs medical bills for claims.
